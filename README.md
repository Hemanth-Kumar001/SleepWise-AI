# SleepWise AI — Standard Machine Learning Project

## Project objective
Predict the dataset's **Quality of Sleep** score (1–10) from recorded sleep, lifestyle and health-related attributes. This is a supervised **regression** problem because the target is a numeric score.

This is an educational analysis of a small, self-reported dataset. It is not a medical diagnostic tool and does not establish that changing a lifestyle variable will cause a change in sleep quality.

## Dataset
Use the Sleep Health and Lifestyle Dataset (374 records commonly distributed in the public Kaggle version).

- Kaggle: https://www.kaggle.com/datasets/uom190346a/sleep-health-and-lifestyle-dataset
- Public CSV mirror: https://github.com/broskunta/Sleep-Health-and-Lifestyle-Dataset/blob/main/Sleep_health_and_lifestyle_dataset.csv

Download the CSV and place it beside the notebook/script, or upload it when prompted in Google Colab. The expected file is `Sleep_health_and_lifestyle_dataset.csv`.

## Models compared
1. Mean baseline — reference point; predicts the average training target.
2. Linear Regression — simple linear baseline.
3. Ridge Regression — linear regression with L2 regularization.
4. K-Nearest Neighbors Regressor — predicts from nearby training records.
5. Decision Tree Regressor — learns rule-based splits.
6. Random Forest Regressor — averages many decision trees.
7. Gradient Boosting Regressor — builds trees sequentially to reduce errors.

## Standard ML workflow
1. Load and inspect the CSV.
2. Remove duplicate records and rows without the target.
3. Convert blood pressure from `systolic/diastolic` text into two numeric columns.
4. Impute missing numeric/categorical inputs, scale numeric columns and one-hot encode categorical columns.
5. Split data into 80% training and 20% held-out test data.
6. Compare regressors using 5-fold cross-validation MAE on training data.
7. Select the model with the lowest mean CV MAE.
8. Report held-out test MAE, RMSE and R² for every model.
9. Save the selected pipeline, comparison table, predictions, plots and permutation feature importance.

**Model selection:** lower MAE and RMSE are better; higher R² is better. The selected model is chosen using cross-validation MAE, not by looking at the test set.

## Important limitations
- The dataset is small (374 records) and its population may not represent other populations.
- `Quality of Sleep` is a subjective score recorded in the dataset, not an objective clinical measurement.
- Performance can vary with the train/test split. Report the actual metrics generated by your run; do not assume a model will achieve a particular score.
- Feature importance indicates what the fitted model uses for prediction; it does not prove medical causation.
